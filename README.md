# tcm-insomnia

中医失眠辨证论治技能 —— 六证型辨证体系、11 首核心方剂、8 则李可医案实录、6 篇证治源流。

## 核心内容

### 六证型辨证体系

| 证型 | 主症 | 病机 | 主方 |
|------|------|------|------|
| 1. 心肾不交（最常见） | 心烦多梦、腰膝酸软、潮热盗汗 | 心火亢于上，肾水亏于下，水火不济 | 心肾不交方 / 交泰丸 |
| 2. 心神失养（心血虚） | 入睡尚可、易醒易惊、面色萎黄 | 心血不足，神不守舍 | 生熟枣仁汤 |
| 3. 胃不和卧不安 | 胃脘胀闷、嗳气、纳差 | 胃气不和，痰浊内阻，胃不和则卧不安 | 加味补中益气汤 |
| 4. 肝经受邪 | 夜卧不安、梦多纷纭、面色潮热 | 肝气郁结化火，内扰心神 | 珍珠母丸（龙齿佐之） |
| 5. 肝肾阴虚 | 头晕、腰酸、口干 | 肝肾阴精不足，虚火上扰 | 加味一贯煎 / 荣肝汤 |
| 6. 痰湿中阻（李可经验） | 头重胸闷、苔腻、多梦 | 痰湿中阻，阴阳不交 | 半夏秫米汤 |

### 常见问题速查（7 组）

心肾不交、心神失养、胃不和、肝经受邪、肝肾阴虚、痰湿中阻、中气不足 —— 每组给出症状组合、证型、主方与要点，速查表标注「最常见，先排此型」。

### 李可体系整合（`like-insomnia.md`）

**阳气论 —— 万病皆损于一元真气**

李可认为失眠的本质是**阳不入阴**，而非阴虚火旺：

- 失眠多属阳虚，不可一概滋阴清热
- 「无苔舌不一定是阴虚，可能是阳虚」（李可独特见解）
- 久病、面色灰暗、但欲寐、脉沉细 → 少阴主证，阳气大虚

**三种失眠辨证模式**：痰湿中阻（半夏秫米汤）／阴虚火旺火不归原（引火汤）／心肾不交（交泰丸）。

**四首核心方剂（李可经验剂量）**

| 方剂 | 组成要点 | 辨证 |
|------|----------|------|
| 半夏秫米汤 | 生半夏 50g、秫米 50g、生姜 50g | 痰湿中阻、心肾不交 |
| 引火汤 | 熟地 90g、巴戟天 30g、茯苓 15g、麦冬 30g、五味子 6g、油桂 3g（米丸吞服） | 阴虚火旺、火不归原 |
| 交泰丸 | 黄连 3g、油桂 3g（后下）、米丸吞服 | 心肾不交 |
| 潜阳丹 | 龟甲 30g、砂仁米 30g、制附片 30–45g、炙甘草 30–60g | 阳浮于上 |

**三种特殊治法**

- **子午时服药法**：子时（23–01 时）一阳生、午时（11–13 时）一阴生，此时服药有利于阴阳平衡 —— 李可多个失眠医案均采用
- **乌梅敛厥阴法**：酸可收涩，敛厥阴以安神
- **童便引火归原**：浊药引火下行

**医案实录 8 则**：医案 17 怔忡阳不潜藏脉数、医案 20 火不归原失眠、医案 21 痰湿中阻心肾不交、医案 22 失眠 20 年阳不入阴、医案 23 阳浮于上寐艰而醒、医案 24 劳倦内伤心肾交虚、医案 25 失眠久延少阴主证、医案 55 多梦阳不入阴。

### 证治源流（`sources/`）

每篇按「经典出处 → 历史沿革 → 代表方剂引文 → 辨证要点」结构编排，附朝代表方演变表（如交泰丸：汉《伤寒论》黄连肉桂配伍 → 明·韩懋命名 → 清·傅青主心肾不交方体系 → 近代·李可引火归原思维）。

## 使用方式

### 导入 AI Agent 技能库

将 `SKILL.md` 放入技能库目录，Agent 会依据 frontmatter 中的 `description` 自动匹配触发条件（用户自述入睡困难/多梦/早醒/心烦/健忘等睡眠问题时触发）。

### 典型工作流

```
用户自述睡眠问题
  → 决策路由树（入睡困难为主 → 早醒易醒 → 胃不和 → 痰湿 → 中气不足）
    → 六证型归属 + 症结
      → 查 modules/ 取方剂组成/加减/禁忌
        → 查 cases/ 找相似医案佐证
          → 查 like-insomnia.md 取李可经验方与特殊治法
            → 按 SKILL.md「五、输出格式」输出
```

### 输出结构

证型 → 症结所在 → 中药内服（方名/来源文献/组成/功效/用法）→ 针灸配穴 → 生活调摄 → 注意事项。

## ⚠️ 重要提示

本仓库为中医学习与知识工程参考，**不构成医疗建议**。

- **半夏秫米汤（生半夏 50g）属大剂量用法**，须在有经验医师指导下使用
- **潜阳丹、附桂理中汤含附子**，须严格掌握煎法（先煎久煎）并观察瞑眩反应
- 失眠常继发于抑郁、焦虑、甲亢等器质性疾病，**长期不眠须先行排查器质性病因**，建议线下就医
- 症状严重或持续超过 2 周，建议线下就医
- 孕妇、儿童、老年人用药须特别注明并建议咨询专业医师
- 本仓库内容依据公开文献整理，实际应用请以执业医师面诊为准
